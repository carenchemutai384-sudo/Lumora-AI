Lumora AI

An AI-assisted learning platform designed to help students understand their academic performance and organize their learning.

🌐 Live Site: https://carenchemutai384-sudo.github.io/Lumora-AI/

About Lumora AI

Lumora AI is a student-focused project exploring how artificial intelligence and software can be used to create a more personalized learning experience.

The project brings together academic performance tools, study planning, progress tracking, and AI-assisted learning features in one platform.

Lumora is an ongoing project that I continue to improve as I learn and experiment with new technologies.

Why I Built Lumora

I wanted to explore how technology could help students better understand their academic performance and organize their learning.

Instead of building a tool that only performs one task, I wanted to create a platform that could bring several parts of the student learning experience together.

Features

- 📊 Performance Prediction — explores academic performance through a student-focused prediction interface.
- 📚 Study Planner — helps students organize their study activities.
- 🤖 AI Coach — an AI-focused learning support feature.
- 📈 Progress Tracking — provides a dashboard for monitoring academic progress.
- 🌙 Dark Mode — provides an alternative interface theme.
- 📱 Responsive Design — designed for both desktop and mobile screens.
- ✨ Animated Interface — includes subtle animations and transitions to improve the user experience.
